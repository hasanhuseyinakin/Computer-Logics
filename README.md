# Computer-Logics
These are a group of Lessons for those who wants to understand the logic behind the computer's incredible calculation and speed. this comprehensive repository guides learners through digital logic design and Arithmetic Logic Unit (ALU) architecture. All circuits and simulations within this project are fully designed and implemented using Logisim, providing a hands-on visual approach to computer hardware fundamentals. Furthermore, the repository is open-source and licensed under the GNU General Public License v2.0 (GPL-2.0), ensuring that anyone is free to use, modify, and share the material. Have fun while learning and exploring the inner world of Computers.
